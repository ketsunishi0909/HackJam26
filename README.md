# HackJam 2026

Website repository for **HackJam 2026**, an MLH-affiliated student hackathon experience.

## Overview

HackJam 2026 is a modern event website designed to present the hackathon, communicate event information clearly, and create an energetic visual experience for prospective hackers, sponsors, and attendees.

## Tech Stack

- Next.js
- Tailwind CSS v4
- GSAP
- Framer Motion

## Focus

- Responsive event UI
- Motion-driven landing-page interactions
- Modern component-based frontend architecture
- Sponsor and event-information presentation
- Mobile-friendly design

## Development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
